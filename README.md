# JavaScript Calculator

## Description

The JavaScript Calculator is a simple web-based
calculator developed using HTML, CSS and JavaScript.

It performs basic arithmetic operations such as
addition, subtraction, multiplication and division.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero validation
- Empty-input validation
- Clear button
- Simple user interface

## How to Run

1. Download or clone the repository.
2. Open the `code` folder.
3. Open `index.html` in a web browser.
4. Enter two numbers.
5. Select an arithmetic operation.
6. View the result.
